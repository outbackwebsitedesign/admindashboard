# Admin Dashboard

A comprehensive bookkeeping and administration dashboard for managing business operations.

## Features

- **Overview**: High-level view of business metrics and performance
- **Books**: Bookkeeping and financial management
- **Operations**: Operational tracking and management
- **Sales**: Sales data and analytics
- **Settings**: Configuration and preferences

## Files

- `Bookkeeping Admin.html` - Main HTML entry point
- `app.jsx` - Main application component
- `charts.jsx` - Chart components and visualizations
- `data.js` - Data management and utilities
- `styles.css` - Application styling
- `ui.jsx` - UI components and elements
- `views_books.jsx` - Books management view
- `views_ops.jsx` - Operations view
- `views_overview.jsx` - Overview dashboard view
- `views_sales.jsx` - Sales analytics view
- `views_settings.jsx` - Settings configuration view

## Getting Started

1. Open `Bookkeeping Admin.html` in a web browser to launch the dashboard
2. Navigate through different sections using the sidebar navigation
3. Configure settings as needed in the Settings section

## Technology

- React (JSX)
- Custom CSS styling
- Chart visualizations
